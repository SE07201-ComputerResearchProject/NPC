Chatbot Prototype

Floating PC build assistant for the whole site.

This demo page now mirrors the widget that can be loaded on every main page. Open the assistant at the bottom-right to test contextual help, build review, compatibility hints, and Gemini-backed answers.

Reads current build The widget inspects saved build state and adapts its guidance based on what the user has already selected.
Quick intervention It can suggest the next missing category, redirect to builder, or push users toward the right product listing.
Compatibility-aware Before asking Gemini, it can call the compatibility API so the advice is grounded in the current build.
Graceful fallback If Gemini is busy, the widget still returns local guidance so the site remains useful.

What this version is meant to do

  • Stay visible on any page without dominating the layout.
  • Guide users toward a complete PC instead of acting like a generic chat box.
  • Point users to dashboard and products with clear next actions.
  • Use the existing backend Gemini proxy and compatibility route.
Suggested flow CPU → Motherboard → RAM → Storage → PSU → Case Once the required core is in place, the assistant can recommend GPU, cooling, and final compatibility review before checkout.
